# ORP

ORP - легкая CLI-панель для управления OlcRTC server instances на Linux.
Утилита создает пользовательские конфиги OlcRTC, регистрирует systemd-сервисы,
запускает их и выводит готовые `olcrtc://` ссылки для подключения. Используется самая быстрая и простая связка jitsi + datachannel

Проект полезен, когда нужно быстро создавать и обслуживать несколько
пользователей OlcRTC на одном сервере без ручного редактирования service-файлов.

## Возможности

- Создание нового пользователя OlcRTC одной командой.
- Генерация случайной Jitsi-комнаты и crypto key для каждого пользователя.
- Создание и управление отдельными systemd-сервисами для пользователей.
- Локальное хранение сгенерированных данных пользователей.
- Изменение базового Jitsi-хоста для новых комнат.
- Просмотр списка пользователей и последних логов сервиса из CLI.

## Требования

- Linux-сервер с systemd.
- Root-доступ для записи в `/opt` и `/etc/systemd/system`.
- Go `1.26.3` или совместимая версия.
- Бинарник OlcRTC по пути `/opt/olcrtc/olcrtc-linux-amd64`.

## Установка

Соберите ORP или скачайте с Releases:

```bash
GOOS=linux GOARCH=amd64 go build -o orp-linux-amd64 .
```

Установите бинарник:

```bash
sudo install -m 0755 orp-linux-amd64 /usr/local/bin/orp
```

Подготовьте рабочие директории:

```bash
sudo mkdir -p /opt/orp/data /opt/olcrtc /opt/olcrtc-users
```

Установите бинарник OlcRTC:

```bash
sudo install -m 0755 olcrtc-linux-amd64 /opt/olcrtc/olcrtc-linux-amd64
```

## Быстрый старт

Укажите Jitsi-хост, который будет использоваться в новых room URL:

```bash
sudo orp changebase meet.example.com
```

Создайте пользователя:

```bash
sudo orp add alice
```

ORP создаст пользовательский конфиг, зарегистрирует systemd-сервис, запустит его
и выведет сгенерированную `olcrtc://` ссылку.

Проверьте список созданных пользователей:

```bash
sudo orp list
```

## Команды

| Команда | Описание |
| --- | --- |
| `orp add <username>` | Создать пользователя, конфиг, systemd-сервис и ссылку подключения. |
| `orp list` | Показать созданных пользователей и сгенерированные ссылки. |
| `orp restart <username>` | Перезапустить systemd-сервис пользователя. |
| `orp logs <username>` | Показать последние 100 строк journalctl для сервиса пользователя. |
| `orp delete <username>` | Остановить, отключить и удалить сервис и директорию пользователя. |
| `orp changebase <host>` | Изменить Jitsi-хост для новых комнат. |

## Создаваемые файлы

| Путь | Описание |
| --- | --- |
| `/opt/orp/config.json` | Конфигурация ORP. |
| `/opt/orp/data/users.json` | Сгенерированные пользователи и данные подключения. |
| `/opt/olcrtc-users/<username>/srv_template.yaml` | Пользовательский конфиг OlcRTC. |
| `/etc/systemd/system/olcrtc-<username>.service` | Пользовательский systemd-сервис. |

## Структура проекта

```text
.
├── main.go
├── cmd/                 # CLI-команды
├── internal/configs/    # Хранение конфигурации ORP
├── internal/storage/    # Хранение данных пользователей
├── internal/systemd/    # Интеграция с systemd
├── internal/templates/  # Встроенные шаблоны конфигов и сервисов
└── internal/users/      # Логика управления пользователями
```

## Примечания

- ORP рассчитан на запуск на Linux с systemd.
- Большинство команд нужно запускать через `sudo`.
- Сгенерированные ссылки содержат чувствительные данные доступа. На общих
  серверах держите `/opt/orp/data/users.json` приватным.
